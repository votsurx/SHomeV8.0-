# 🏠 SHome v8.4.0 — умный дом на Flutter

[![Version](https://img.shields.io/badge/version-8.4.0-blue)](https://github.com/votsurx/SHome-Releases/releases)
[![Platform](https://img.shields.io/badge/platform-Android-lightgrey)]()

SHome — локальная панель управления умным домом с интеграциями **Tuya**,
**Zigbee2MQTT**, **Frigate NVR**, определением **присутствия** по Wi-Fi/GPS,
уведомлениями через VK и SMS и резервными копиями в Mail.ru Cloud.

Интерфейс приложения поддерживает русский и английский языки, а также режим
«Как в системе». Выбор языка доступен при первом запуске и в настройках.

---

## 📱 Возможности

### 🏠 Устройства умного дома

- **Tuya** — управление устройствами в локальной сети через TinyTuya:
  - розетки и выключатели на 1/2/3 канала;
  - датчики, шторы, лампы и кондиционеры;
  - составные устройства `compound`;
  - настройка DPS-карты.
- **Zigbee2MQTT** — интеграция через MQTT:
  - список устройств и их состояний;
  - данные датчиков, заряд батареи и качество связи;
  - доступность online/offline.
- **Комнаты** — сортировка, фильтрация и перетаскивание устройств.
- **Сцены** — ручной запуск, расписание, датчики и события присутствия.
- **Таймеры** — отложенное включение и выключение устройств.
- **Журнал событий** — быстрый показ последних событий из `StatsCache`,
  постраничная загрузка истории из SQLite и дедупликация записей.
- **Энергомониторинг** — потребление и стоимость электроэнергии.

### 📹 Видеонаблюдение

- Интеграция с **Frigate NVR** через MQTT и REST API.
- Снимки камер и статистика Frigate.
- Настройка камер, комнат, интервала снимков и RTSP-порта.
- События детекции и уведомления.

### 📍 Присутствие

- Получение локального HTTP heartbeat от Companion на порту `7777`.
- Использование облачного источника, если локальный heartbeat устарел.
- Определение состояний «дома», «рядом», «ушёл», «неизвестно».
- Расчёт расстояния до дома по GPS, если координаты доступны.
- Настройка домашней зоны, радиуса и тайм-аута.
- Смена статусов присутствия записывается в журнал событий.
- Сцены могут запускаться по событиям присутствия.

### 🔔 Уведомления

- **VK Bot** и **SMS** с раздельными настройками каналов.
- Выбор событий и тревог для уведомлений.
- Расписания отправки и настройка антидребезга.
- Уведомления для устройств Tuya, Zigbee2MQTT и Frigate.

### ☁️ Mail.ru Cloud и резервные копии

- Подключение через WebDAV.
- Ручная загрузка и восстановление конфигурации.
- Автоматическая синхронизация отключена.
- Ротация резервных копий в облаке.
- Локальное шифрование всего контейнера конфигурации с помощью **AES-256-GCM**.
- Перенос ключа шифрования между устройствами через QR-код.

#### Формат и ключ резервной копии

Зашифрованный контейнер резервной копии начинается с:

```text
SHBK1:

QR-код для переноса ключа использует отдельный формат:

shome-backup-key:v1:<base64url-key>

Ключ создаётся пользователем и хранится локально в защищённом хранилище. Он не загружается в Mail.ru Cloud. При отключении облака локальный ключ не удаляется.

Резервные копии старого формата XOR + Base64 не поддерживаются. Для восстановления новой зашифрованной копии нужен соответствующий ключ. Потерянный ключ восстановить из облака невозможно.

Скачайте APK из раздела GitHub Releases.

🚀 Быстрый старт
Пройдите онбординг и создайте комнаты.
Добавьте Tuya-устройства через сканер или укажите Device ID, Local Key и IP.
Настройте MQTT-брокер для Zigbee2MQTT и Frigate.
Добавьте камеры Frigate.
Настройте уведомления VK и/или SMS.
При необходимости настройте присутствие и установите приложение Companion.
Для резервного копирования подключите Mail.ru Cloud и создайте ключ AES.
Для восстановления на другом устройстве перенесите ключ через QR-код, подключите облако и выберите нужную резервную копию.
🔐 Безопасность резервных копий
SHome шифрует конфигурацию до её загрузки в облако. Ключ хранится локально в защищённом хранилище, а QR-код предназначен для переноса ключа между доверенными устройствами.

Не показывайте QR-код посторонним и храните резервную копию ключа безопасно.
