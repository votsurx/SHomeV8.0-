# 🏠 SHome v8.1.48 — Умный дом на Flutter

[![Version](https://img.shields.io/badge/version-8.1.47-blue)](https://github.com/votsurx/SHome-Releases/releases)
[![Platform](https://img.shields.io/badge/platform-Android-lightgrey)]()

Локальный контроллер умного дома с поддержкой **Tuya**, **Zigbee2MQTT**,
**Frigate NVR**, **присутствия** по Wi-Fi/GPS, **облачной синхронизацией**
через Mail.ru Cloud и **уведомлениями** через VK и SMS.

---

## 📱 Основные возможности

### 🏠 Умный дом
- **Tuya** — управление по локальной сети (tinytuya)
    - Розетки, выключатели (1/2/3 канала), датчики, шторы, лампы, кондиционеры
    - Универсальное составное устройство (`compound`) с редактором DPS-карты
- **Zigbee2MQTT** — интеграция через MQTT
    - Список устройств, состояния (battery, linkquality, sensor data)
    - **Availability** — online/offline в реальном времени
- **Frigate NVR** — интеграция через MQTT + REST API
    - Камеры, статистика (CPU, RAM, детекторы)
    - Настройки камеры: название, комната, labels, snapshot interval, RTSP порт
    - Снимки в реальном времени
- **Комнаты** — фильтрация, drag & drop
- **Сцены** — ручные, по времени, по датчику, по присутствию
- **Таймеры** — отложенное вкл/выкл
- **Энергомониторинг** — мощность, напряжение, ток, кВт·ч
- **Журнал событий**

### 📹 Видеонаблюдение
- **Frigate NVR** — MQTT события, REST API, снапшоты
- **Тревоги** через VK

### 📍 Присутствие
- **Heartbeat** — Companion → SHome по HTTP (порт 7777), **0 облака** когда дома
- **Fallback на облако** — если heartbeat старше 90 сек
- Определение «дома / рядом / ушёл / неизвестно»
- Радиус и тайм-аут настраиваются
- Триггеры сцен по событиям присутствия

### 🔔 Уведомления
- **VK Bot** — с расписанием и категориями
- **SMS** — через `MethodChannel`
- Раздельные расписания для VK и SMS
- Категории: сцены, устройства, тревоги, ошибки

### ☁️ Облако Mail.ru
- Резервные копии через WebDAV
- **Ручная** загрузка (автосинхронизация отключена)
- Ротация: 5 копий в облаке
- Шифрование бекапов (XOR + Base64)

### 🎨 Интерфейс
- Material 3 с Dynamic Color
- Адаптивная сетка (2-5 колонок)
- Тёмная/светлая/авто тема
- Время + погода (wttr.in) в AppBar
- Сканер Tuya-устройств (порты 6666-6668-7000)

- Проверка через GitHub Releases
- Скачивание и установка APK с прогресс-баром

## 🦾 Универсальное составное устройство

Один тип `compound` заменяет пылесосы, кондиционеры, увлажнители:

1. Добавьте устройство → Тип: **Универсальное устройство**
2. Шестерёнка → **DPS-карта** → **Добавить DPS**
3. Укажите: номер, название, тип (`bool`/`value`/`enum`/`slider`),
   роль (`main`/`action`/`toggle`/`info`/`status`/`slider`/`enum`/`channel`),
   иконку
4. Виджет и опрос строятся автоматически из карты

Переключатели **show_on_card** для info/status DPS управляют
отображением на карточке главного экрана.

## 🚀 Быстрый старт

1. Пройдите онбординг (создайте комнаты)
2. **Tuya** — Сканер → добавьте устройства (Device ID, Local Key, IP)
3. **Zigbee** — Настройки → MQTT (указать брокер)
4. **Frigate** — Настройки → Frigate (host/port) → Меню → Frigate → «+» на камерах
5. **Уведомления** — Настройки → Уведомления (VK / SMS)
6. **Облако** — Меню → Облако (для бекапов)
7. **Присутствие** — Меню → Присутствие (Wi-Fi/GPS-отслеживание)
8. **Companion** — отдельное приложение для heartbeat (порт 7777)
