# 🏠 SHome v8.3.1 — Умный дом на Flutter

[![Version](https://img.shields.io/badge/version-8.3.1-blue)](https://github.com/votsurx/SHome-Releases/releases)
[![Platform](https://img.shields.io/badge/platform-Android-lightgrey)]()

Локальный контроллер умного дома с поддержкой **Tuya**, **Zigbee2MQTT**,
**Frigate NVR**, определения **присутствия** по Wi-Fi/GPS, облачного
резервного копирования через Mail.ru Cloud и уведомлений через VK и SMS.

---

## 📱 Основные возможности

### 🏠 Умный дом

- **Tuya** — управление устройствами по локальной сети через TinyTuya:
    - розетки;
    - выключатели на 1/2/3 канала;
    - датчики;
    - шторы;
    - лампы;
    - кондиционеры;
    - универсальные составные устройства `compound`;
    - редактор DPS-карты.
- **Zigbee2MQTT** — интеграция через MQTT:
    - список устройств;
    - состояния устройств;
    - battery;
    - linkquality;
    - данные датчиков;
    - статус доступности online/offline в реальном времени.
- **Frigate NVR** — интеграция через MQTT и REST API:
    - список камер;
    - статистика CPU, RAM и детекторов;
    - настройка названия и комнаты камеры;
    - настройка labels;
    - интервал снимков;
    - RTSP-порт;
    - снимки в реальном времени.
- **Комнаты**:
    - фильтрация устройств;
    - сортировка;
    - drag & drop.
- **Сцены**:
    - ручной запуск;
    - запуск по расписанию;
    - запуск по датчику;
    - запуск по событиям присутствия.
- **Таймеры** — отложенное включение и выключение устройств.
- **Энергомониторинг**:
    - мощность;
    - напряжение;
    - ток;
    - кВт·ч.
- **Журнал событий**:
    - быстрый показ последних событий из `StatsCache`;
    - загрузка истории из SQLite;
    - постраничная подгрузка;
    - автоматическое добавление новых событий;
    - дедупликация событий между памятью и базой данных.

### 📹 Видеонаблюдение

- При нахождении дома используется локальное соединение без облака.
- **Fallback на облако**, если последний heartbeat старше 90 секунд.
- Определение состояния:
    - дома;
    - рядом;
    - ушёл;
    - неизвестно.
- Настройка радиуса определения и тайм-аута.
- Запуск сцен по событиям присутствия.
- Поддержка определения присутствия по Wi-Fi и GPS.

## 🔐 Безопасные резервные копии

Начиная с версии **8.3.1**, резервные копии шифруются с использованием
**AES-256-GCM**.

Ранее использовавшееся шифрование через XOR и Base64 удалено. Base64 не
является алгоритмом шифрования, поэтому он больше не используется как
средство защиты данных.

### Что шифруется

Вся конфигурация приложения объединяется в один JSON-контейнер и затем
шифруется целиком.

В зашифрованный контейнер могут входить:

- настройки приложения;
- настройки MQTT;
- параметры Tuya;
- параметры Zigbee2MQTT;
- настройки Frigate;
- настройки Mail.ru Cloud;
- параметры VK;
- пароли;
- токены;
- другие конфигурационные данные.

Секретные поля больше не шифруются отдельно с помощью слабого XOR-механизма.
Они защищаются общим AES-256-GCM-контейнером.

📱 Перенос ключа через QR-код
SHome поддерживает перенос ключа резервного копирования между устройствами через QR-код.

Экспорт ключа
На исходном устройстве:

Откройте настройки облачного резервного копирования.
Создайте ключ резервного копирования, если он ещё не создан.
Выберите отображение QR-кода ключа.
Оставьте QR-код открытым на экране устройства.
Импорт ключа
На новом устройстве:

Откройте настройки облачного резервного копирования.
Выберите импорт ключа через QR-код.
Разрешите приложению доступ к камере.
Наведите камеру на QR-код исходного устройства.
Дождитесь завершения импорта ключа.
Загрузите резервную копию из Mail.ru Cloud.
Восстановите конфигурацию.
Формат QR-кода
QR-код содержит ключ в формате Base64URL с версией протокола:

shome-backup-key:v1:<base64url-key>

## 🚀 Быстрый старт

1. Пройдите онбординг (создайте комнаты)
2. **Tuya** — Сканер → добавьте устройства (Device ID, Local Key, IP)
3. **Zigbee** — Настройки → MQTT (указать брокер)
4. **Frigate** — Настройки → Frigate (host/port) → Меню → Frigate → «+» на камерах
5. **Уведомления** — Настройки → Уведомления (VK / SMS)
6. **Облако** — Меню → Облако (для бекапов)
7. **Присутствие** — Меню → Присутствие (Wi-Fi/GPS-отслеживание)
8. **Companion** — отдельное приложение для heartbeat (порт 7777)
